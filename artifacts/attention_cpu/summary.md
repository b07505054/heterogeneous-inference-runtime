# Operator-level FP32 CPU attention validation

This artifact summarizes the narrow executable contract generated by the compiler for
`cpu_attention_prefill_fp32` and `cpu_attention_decode_fp32`. It is not a full-model or
production-serving claim.

The production output comes from the native C++ artifact. The Python implementation is
used only as a high-precision correctness oracle. Both host and Raspberry Pi runs used
10 warmups, 100 samples, and three complete already-loaded runner invocations per sample.

All cosine similarities exceed 0.9999999999998; all outputs have zero NaNs and infinities.
Every trace records one artifact load, one worker start, two reusable buffer allocations,
and zero runtime reselections. The Pi compiler-plan trace separately proves that the
Pi-specific compiler-generated plan validates and calls both exact native entry points.

Unsupported: full-model inference, runtime KV-cache ownership/lifetime, paged KV cache,
continuous batching, FlashAttention, fusion, GQA/MQA, GPU/distributed attention, and a
predictive cost model.
